Ardyn Voice Widget

Embeddable AI SDR voice assistant — Preact + pipecat + LiveKit + Deepgram

🚀 Quick Start

The widget is loaded. Click the floating mic button in the bottom-right corner to start a voice conversation.

Or try the programmatic controls below.

📦 HTML Embed (data attributes)

Alternative: add data-ardyn-voice-widget to any element. The widget auto-mounts on DOMContentLoaded.

<!-- Auto-mounting widget --> <div data-ardyn-voice-widget data-ardyn-token="YOUR_LIVEKIT_TOKEN" data-ardyn-brand="Ardyn" data-ardyn-position="bottom-right" data-ardyn-auto-connect="true" data-ardyn-greeting="Hey! I'm Ardyn." ></div>

🔌 Programmatic API

// ES Module import { mount, unmount } from '@ardyn/voice-widget'; const api = mount('#my-container', { livekitToken: 'your-token', brandName: 'MyBrand', brandColor: '#6366f1', position: 'bottom-right', theme: 'dark', greetingMessage: 'Hello! How can I help?', onStateChange: (state) => console.log(state), onMessage: (msg) => console.log(msg), onError: (err) => console.error(err), }); // Later... unmount();
<!-- Script tag (IIFE) --> <script src="ardyn-voice-widget.iife.js"></script> <script> ArdynVoiceWidget.mount( document.getElementById('widget'), { livekitToken: 'your-token' } ); </script>

✨ Features

  • Preact-based (~50KB gzipped target)
  • Real-time voice via Deepgram STT → ElevenLabs TTS
  • LiveKit WebRTC transport with pipecat pipeline
  • Text fallback when mic is unavailable
  • User interruption (tap to stop AI mid-speech)
  • Dark & light themes
  • Responsive, mobile-friendly
  • IIFE, ES, and UMD bundles
  • Zero host-page conflicts (CSS namespaced, Shadow-ready)
